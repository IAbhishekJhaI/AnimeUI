Sakuga VFX

Twenty ordinary controls that react like anime: squash and overshoot on springs, and drawn effects (smoke, impact bursts, splashes, slashes) with manga sound-effect lettering. Each one is a single file with no dependencies. The last eight are an extended set built on the same core.

Theme override: The repo on GitHub ↗ @crtvTeknologist on X ↗

Effects are drawn on one canvas over the page and switch off for prefers-reduced-motion. Every colour is a --sk-* variable you can override.

This dialog drops in on a spring over a manga screentone backdrop, slams into place with a back-layer starburst and ドン!, and leaves by shrinking cleanly to zero.
